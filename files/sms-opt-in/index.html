Message_Flow

How end-users consent to receive messages from DeltaIQ (web form only). Every manual step a subscriber takes is listed below.

Consent method: Website / web form only. No SMS keyword opt-in. No verbal or paper opt-in.

Primary path — new subscriber (Subscribe Now → consent modal → Stripe Checkout)

  1. Visit the website. The end user opens https://getdeltaiq.com/. Public SMS disclosures are always visible at https://getdeltaiq.com/#consent (message frequency; Msg&data rates may apply; STOP / HELP; links to Privacy Policy and Terms).
  2. Click Subscribe Now. The end user clicks the Subscribe Now button on the homepage (hero or pricing section). This opens a consent modal on getdeltaiq.com before any Stripe Checkout session is created.
  3. Read required acknowledgments (purchase — not SMS). The modal titled “Before you subscribe” shows three checkboxes. All three start unchecked. The first two are required to continue to checkout:
    • Agree to the Terms of Service and Privacy Policy; confirm age 18+ and U.S. resident.
    • Confirm reading the Important Disclosures.
    Checking these two boxes does not enroll the user in SMS.
  4. Optional SMS consent action (affirmative opt-in). The third checkbox is optional SMS only. It is separate from purchase. Exact live label: “Would you also like to receive optional text notifications when new subscriber dashboard content is available? Optional. Recurring automated texts prompt you to sign in at My Account; they do not include market or ticker detail. Message frequency varies with publication activity. Message and data rates may apply. Reply STOP to opt out, HELP for help, or email support@getdeltaiq.com. You can finish checkout and use the dashboard without SMS. Opting out of SMS does not by itself cancel billing.”
    • The checkbox starts unchecked.
    • The end user may leave it unchecked and still continue to checkout (decline path).
    • Only if the end user affirmatively checks this box is SMS consent recorded.
  5. Continue to secure checkout. The end user clicks Continue to secure checkout. getdeltaiq.com calls the DeltaIQ API to create a Stripe Checkout Session and records ack_sms=true or ack_sms=false in Session metadata (fail-closed: SMS entitlement follows this flag only).
  6. Enter mobile phone number on Stripe Checkout. The end user is redirected to Stripe-hosted Checkout at checkout.stripe.com (Stripe Checkout screenshot below). On that page the end user manually:
    • Enters email
    • Enters mobile phone number (required field for contact / SMS delivery destination)
    • Enters payment and billing address
    • Checks Stripe’s required Terms of Service / Privacy Policy acknowledgment (18+, US resident)
    Product description on the left panel states that SMS is optional and texts do not include market, ticker, price, or publication detail. When the user opted into SMS on getdeltaiq.com, the Stripe submit line states: “You opted into optional SMS on getdeltaiq.com. Msg&data rates may apply. Reply STOP to opt out, HELP for help.”
  7. Complete checkout / Start trial. The end user clicks Start trial (or pay). Payment is processed by Stripe. DeltaIQ provisions the subscription.
    • If ack_sms=true and a phone number was provided: DeltaIQ stores SMS opt-in and sends a one-time welcome SMS confirming enrollment.
    • If SMS was not checked: no SMS is sent; the subscriber still receives dashboard access.

Secondary path — existing paid subscriber (My Account web form)

  1. Sign in to My Account. A paid subscriber who declined SMS at checkout may later visit https://www.getdeltaiq.com/account, sign in, and open the Profile / Text notifications section.
  2. Enable text notifications. The page states that optional SMS notifies the user to sign in when new dashboard content is available, and that Reply STOP opts out of texts (billing continues until canceled). The subscriber affirmatively enables text notifications and confirms a prompt that includes: message frequency; message and data rates may apply; Reply STOP to opt out; HELP for help. DeltaIQ then records SMS opt-in and sends the same one-time welcome SMS.

What happens after consent

  • Welcome SMS (once): confirms optional texts that prompt sign-in when new dashboard content is available; includes frequency, Msg&data rates, STOP, HELP.
  • Recurring notifications: short texts with a link to sign in at My Account only — no market/ticker/price/publication body.
  • Opt-out: Reply STOP (also STOPALL, UNSUBSCRIBE, CANCEL, END, QUIT) → auto-reply confirms texts stopped; billing unchanged.
  • Help: Reply HELP or INFO → auto-reply with support@getdeltaiq.com and account URL.
